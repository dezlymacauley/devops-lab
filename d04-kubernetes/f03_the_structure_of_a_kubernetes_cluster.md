# The structure of a Kubernetes cluster
_______________________________________________________________________________

```
Kubernetes Cluster
│
├── Control Plane
│   │
│   ├── API Server
│   ├── Scheduler
│   ├── Controller Manager
│   └── etcd
│
└── Worker Nodes
    │
    ├── Worker Node 1
    │   │
    │   ├── Pod
    │   │   ├── Container
    │   │   └── Container
    │   │
    │   └── Pod
    │       └── Container
    │
    ├── Worker Node 2
    │   │
    │   ├── Pod
    │   │   └── Container
    │   │
    │   └── Pod
    │       └── Container
    │
    └── Worker Node 3
        │
        └── Pod
            └── Container
```
