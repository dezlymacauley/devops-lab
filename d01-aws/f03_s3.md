# S3 (Simple Storage Service)
_______________________________________________________________________________

How to create an `s3` bucket

E.g. I want to create an `s3` bucket called `booru-assets`

```bash
aws s3 mb s3://booru-assets
```

You should see an output like this:
```
make_bucket: booru-assets
```
_______________________________________________________________________________

List all of the `s3` buckets in your account
```bash
aws s3 ls
```

You should see an output like this:
```
2026-09-19 14:01:34 booru-assets
```
_______________________________________________________________________________

Upload a file to an `s3` bucket.

E.g. I want to upload `blonde_profile_pic.jpg`,
which is located at:
```
/home/dezlymacauley/shared-assets/blonde_profile_pic.jpg
```

The syntax is:
aws s3 cp path-to-file s3://name-of-bucket/name-of-file

```bash
aws s3 cp \
    /home/dezlymacauley/shared-assets/blonde_profile_pic.jpg \
    s3://booru-assets/blonde_profile_pic.jpg
```

You should see an output like this if it worked:
```
upload: ../../../../../../shared-assets/blonde_profile_pic.jpg 
to s3://booru-assets/blonde_profile_pic.jpg
```
_______________________________________________________________________________

How to list the contents of a specific `s3` bucket
```
aws s3 ls s3://booru-assets/
```

You should see this:
```
2026-09-19 15:38:11     119330 blonde_profile_pic.jpg
```
_______________________________________________________________________________

How to check if a file exists in an s3 bucket
```bash
aws s3api head-object \
    --bucket booru-assets \
    --key blonde_profile_pic.jpg
```

If the file does not exist, you'll get this:
```
aws: [ERROR]: 
An error occurred (404) when calling the HeadObject operation: Not Found
```

If the file exists, you'll get its metadata in JSON format:
```
{
    "AcceptRanges": "bytes",
    "LastModified": "2026-09-19T13:38:11+00:00",
    "ContentLength": 119330,
    "ETag": "\"18572d9dd7a15ab599def1b9a7192fdd\"",
    "ContentType": "image/jpeg",
    "Metadata": {},
    "StorageClass": "STANDARD"
}
```
