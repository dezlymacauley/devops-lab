# Basic format of an IPv4 address
_______________________________________________________________________________

## IPv4 address in decimal format (aka base-10)

- Decimal format (aka base-10) is the most common way that 
you'll see an IPv4 address displayed.

- An IPv4 address is made up of four digits.

- The lowest value that each of those four digits can be set to is `0`
- E.g. `0.0.0.0`

- The highest value that each of those four digits can be set to is `255`
- E.g. `255.255.255.255`
_______________________________________________________________________________

## IPv4 address in binary format (aka base-2)

When it comes to IPv4 addresses,
the binary representation of a base-10 value will always be 8 digits

#### Note: 
- I will add a guide later on how to convert a decimal value into a binary
value. But for now, I've just listed examples.
_______________________________________________________________________________

### Example 1: `0.0.0.0`
- Decimal (base-10): 0        . 0        . 0        . 0
- Binary (base-2):   00000000 . 00000000 . 00000000 . 00000000

### Example 2: `255.255.255.255`
- Decimal (base-10): 1        . 1       . 1        . 1
- Binary (base-2):   11111111 . 1111111 . 11111111 . 11111111
