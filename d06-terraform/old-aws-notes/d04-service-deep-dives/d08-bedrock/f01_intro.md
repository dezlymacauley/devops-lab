# Amazon Bedrock
_______________________________________________________________________________

This is Amazon's fully managed platform for building 
generative AI applications.

Bedrock allows you to use many AI models using a single API.

It can be used to create AI-powered applications that require:
- Text responses (Including Code Generation)
- Audio to text conversions (Summarizing Meetings)
- AI-powered image or video generation (Content Creation)
- Agents and multi-agent functionality
_______________________________________________________________________________

Types of models:

1. LLM (Chat bots)
2. Image Models
3. Embedding Models (Turns text into numbers, aka vectors, so that you can
search by meaning. This is what powerers RAG)
