# ECS Intro
_______________________________________________________________________________

ECS stands for `Elastic Container Service`

ECS allows you to run Docker containers on AWS
_______________________________________________________________________________

## ECS Cluster

- An ECS Cluster is a logical grouping of tasks and services.
- An ECS Task is a Docker container that is currenty running.

- Each Docker container (or task as they are calleed in AWS),
has a `task definition`.

- This defines what you want run.
