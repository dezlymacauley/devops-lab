
_______________________________________________________________________________

### depends_on
This is used to define dependencies between resources
_______________________________________________________________________________

### `count` and `for_each`
Allows you to create multiple resources of the same type
_______________________________________________________________________________

### `provider`
Defines which provider to use for a specific resource
_______________________________________________________________________________

### `create_before_destroy`
Terraform's default behaviour is to delete a resource,
and then delete it. This overrides that behaviour
_______________________________________________________________________________

### `prevent_destroy`
Prevents a resource from being deleted.
_______________________________________________________________________________
