# IAM Roles
_______________________________________________________________________________

Certain AWS Services such as `EC2` require permission to 
perform actions on your account.

- An `IAM Role` allows you to give the AWS Service that permission. 
_______________________________________________________________________________

Search for the `IAM` services, then look for `Access Management` in 
the sidebar. Then click on `Roles`
_______________________________________________________________________________

Click `Create role`
_______________________________________________________________________________

Select the following options:

- Trusted entity type: `AWS Service`
- Service or use case: `EC2`
_______________________________________________________________________________

Then you can attach a policy like `IAMReadOnlyAccess`
_______________________________________________________________________________

- Role Name: `demo-role-for-ec2`

_______________________________________________________________________________

This policy will be autogenerated for you
```json
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Action": [
                "sts:AssumeRole"
            ],
            "Principal": {
                "Service": [
                    "ec2.amazonaws.com"
                ]
            }
        }
    ]
}
```
_______________________________________________________________________________

Add tags

- Key: `iam-roles`, Value: `demo-role-for-ec2`
_______________________________________________________________________________

Click `Create role`
_______________________________________________________________________________
