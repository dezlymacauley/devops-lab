# User-specific access policy
_______________________________________________________________________________

Search for the `IAM` service
_______________________________________________________________________________

Click `IAM Users` and select your user
_______________________________________________________________________________

Click `Add permissions`, then click `Add permissions`
_______________________________________________________________________________

Select this option

- Permission options: `Attach policies directly`
_______________________________________________________________________________

E.g. 

You can select `IAMReadOnlyAccess` to give the user permission to read IAM 
information.
_______________________________________________________________________________

Click `next`
_______________________________________________________________________________
