# Creating an access key
_______________________________________________________________________________

Login using the `Root User Account`, 
or login as an `IAM User` that has the `AdministratorAcess` policy
_______________________________________________________________________________

Search for the `IAM` service
_______________________________________________________________________________

Click `Create acess key`
_______________________________________________________________________________

Select this option:

- Use case: `Command Line Interface (CLI)`
- Description tag: `ftawsoct2026dezlymacauley_aws_cli_access_key_dezly_2026_10_29`

#### Note: 
- For the `Description tag` I prefer this format:

[ AWS Account Alias ]_aws_cli_access_key_[ Name of IAM user]_[ Date created ]
