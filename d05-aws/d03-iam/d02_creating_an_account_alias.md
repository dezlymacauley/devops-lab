Login to AWS using the root user account.
_______________________________________________________________________________

Use the search bar to search for the `IAM` service
_______________________________________________________________________________

You should see `AWS Account` on the right, and `Account Alias` below that.
_______________________________________________________________________________

Click `create` to create a unique account alias for your AWS account.
_______________________________________________________________________________

Make the account alias the same as the account name to keep things simple.  

E.g. 
```
ftawsoct2026dezlymacauley
```
_______________________________________________________________________________

You will get a `Sign-in URL for IAM users in this account` that looks 
like this: 
```
https://ftawsoct2026dezlymacauley.signin.aws.amazon.com/console
```

Save this link as a bookmark.
